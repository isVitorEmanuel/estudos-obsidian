Python é uma linguagem fácil de aprender e poderosa que possui estrutura de dados de alto nível eficientes e uma abordagem simples e efetiva de orientação a objetos, além de possuir uma sintaxe elegante e tipagem dinâmica.

Seu interpretador é capaz de estender bibliotecas, funções e tipos de dados implementados em C, C++ ou outras linguagens baseadas em C.

> Se quiser apronfundar: [Referência de Bibliotecas](https://docs.python.org/pt-br/3.15/library/index.html#library-index)

Python é fácil de usar como *scripts* em *bash*, mas é poderosa como qualquer outra linguagem. Isso a torna poderosa e eficiente, o que permite seu uso em diversos domínios e problemas. Python é um linguagem **interpretada**, dando uma maior agilidade e flexibilidade no desenvolvimento.

Programas em Python são mais curtos que em C, C++ ou Java, devido:

- os tipos de alto nível permitem que você expresse operações complexas em um único comando;
- a definição de bloco é feita por indentação ao invés de marcadores de início e fim de bloco;
- não há necessidade de declaração de variáveis ou parâmetros formais;
